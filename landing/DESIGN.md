# XMark 产品页设计约定

## 1. 视觉主题
用户指定沿用 Hoot 的浅色苹果风。全页固定浅色，产品截图是主视觉；使用同一家族的居中大标题与系统字体，这是明确的参考要求。版式变化 4/10、动效 2/10、信息密度 4/10。现状基线：720px 内容区、40px 产品名、三列小卡片、随系统切换明暗、12px 圆角、琥珀重音。

## 2. 色板
背景 #ffffff，分区 #f5f5f7，正文 #1d1d1f，次要 #6e6e73，交互 #0071e3，分隔 #e5e5ea。保留项目原有 Logo 和截图，不修改 App 主题。

## 3. 排版
SF Pro / PingFang 系统栈。大标题 40–68px，移动端 28–40px；段落 15–18px，行高 1.7–1.85；数字 tabular-nums。标题 balance，正文 pretty。禁用斜体及外部字体请求。

## 4. 组件
轻薄粘性导航、蓝色胶囊下载按钮、次级 GitHub 链接、可放大的真实产品图、原生 details 问答和 dialog 图片预览；键盘焦点可见，Esc 关闭并返回触发点。

## 5. 布局
最大宽度 1160px，段落最大 65ch。Hero 后按真实使用流程组织内容；功能区以两栏说明、分隔线和灰底分区区分，不把所有信息装入等宽卡片。

## 6. 深度层级
仅产品图使用柔和阴影，正文分区不悬浮；导航浮层使用轻度模糊。背景保持纯色，不用渐变光晕。

## 7. 内容边界
首屏须说明产品用途、Apple Silicon 支持、当前版本、下载与源码入口。依据 README 和已发布功能，不把开发中内容宣传为已发布。保留许可、第三方归属、安装限制及既有语言能力。发布参数继续由 release.json 注入，不改下载源或更新清单。

## 8. 响应式
小于 760px 时两栏折为单列；小于 640px 收简导航，保留语言切换及下载。按钮不折行，图片等比显示，正文可换行；检查 320px、390px、1280px 与英文长标题。

## 9. 动效
仅按钮反馈 120–160ms、轻度 hover 和用户触发的图片预览；不自动播放、不滚动编排。尊重 prefers-reduced-motion，键盘动作不添加动画。
