## Default Permission

Read files inside a folder the user picked with the system document picker.

#### This default permission set includes the following:

- `allow-pick-folder`
- `allow-restore-folders`
- `allow-forget-folder`
- `allow-list-folder`
- `allow-read-text`
- `allow-read-bytes`
