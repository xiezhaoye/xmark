# XMark

[English](README.md) · **简体中文**

> **XMark 是 [VMark](https://github.com/xiaolai/vmark)（作者 Xiaolai Li）的非官方分支版本。**
> 本项目与原作者无关，也未获得原作者的认可或背书；VMark 本身的一切功劳归原作者所有。
> 使用 XMark 遇到问题，请在**本仓库**反馈，不要提交到原项目。

XMark 保留了 VMark 的全部功能，主要改造了文件夹和工作区的展示方式：三栏布局、工作区**分组**，以及栏位的收起。

## XMark 做了哪些改动

**三栏布局**：工作区 · 文件树 · 文件内容

- 第一栏按**完整的文件夹名**列出已打开的工作区（两个都叫 `wiki` 的文件夹都显示为 `wiki`，鼠标悬停可看到完整路径），拖动右边缘可以调整宽度。
- 去掉了原来悬停在每个工作区上的「复制」小按钮；复制到新窗口、移到新窗口、关闭都放在右键菜单里。

**工作区分组**

- 点第一栏底部的**新建分组**创建分组；在工作区上右键，或点分组右侧的 **+**，把文件夹加进分组。同一个文件夹可以属于多个分组。
- 点分组名展开或收起。分组会被保存，重启后依然在；分组里尚未打开的文件夹以空心图标显示，点击即可打开。
- 没有归入任何分组的已打开工作区，显示在**未分组**里。

**可收起的栏位**

- 两个侧栏收起后不会完全消失，而是变成一条窄竖条。鼠标移上去会高亮提示，点竖条任意位置即可重新展开。`Cmd+\` 可收起或展开文件栏。

**其他优化**

- **设置 → 外观 → 侧栏文字大小**（13–16 px），同时作用于前两栏，行高随文字变化。
- 在文件树里点文件夹那一行即可展开或收起；行不再支持拖拽，触控板第一次点击就能生效。
- 文件树工具栏：左边是展开/折叠/显示全部文件，右边是新建文件和新建文件夹，文件/大纲/历史记录的切换按钮移到了底部；「显示全部文件」改为眼睛图标，悬停提示会说明点击后的效果。

## 构建 XMark

目前还没有 XMark 的安装包，需要从源码构建，步骤见英文 README 中的 [Building from Source](README.md#building-from-source)。实际构建中的两点经验：

- 使用 Node.js 22 或 24（Node 25 会被部分依赖的版本检查拒绝）。
- 第一次运行前先构建一次 MCP 辅助程序：`pnpm --dir server/mcp build:sidecar`，再运行 `pnpm tauri:dev`。

目前 App 内部仍显示 **VMark** 的名称，并沿用 VMark 的应用标识；App 本身的改名会在后续完成。
